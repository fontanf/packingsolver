MILP assignment¶

Objectives¶

This algorithm solves the feasibility, knapsack, bin-packing and variable-sized-bin-packing objectives.

It doesn’t model the nesting lengths, the maximum stackability and the maximum weight after constraints.

Principle¶

It solves the classical assignment (“Kantorovich”) mixed-integer linear program (MILP): each item is assigned to a bin, and the items assigned to a bin must fit in it. Depending on the objective, it is the model of the variable-sized bin packing problem, of the multiple knapsack problem, of the corresponding feasibility problem (all the items in the available bins), or of the bin packing problem where the bin types are used in the order in which they are given.

Model¶

Input:

  • bin types \(t = 1, \ldots, m\); for each bin type \(t\): a length \(L_t\), a maximum weight \(W_t\), a cost \(c_t\), a minimum and a maximum number of copies \(m_t\) and \(M_t\), and, for each resource \(r\), a capacity \(C_{t,r}\); the bin instances \((t, k)\), \(k = 1, \ldots, M_t\), are the copies of the bin types

  • item types \(i = 1, \ldots, n\); for each item type \(i\): a length \(\ell_i\), a weight \(w_i\), a profit \(p_i\), a minimum and a maximum number of copies \(q^{\min}_i\) and \(q_i\), and, for each resource \(r\), the consumption \(a_{i,r,c}\) of its \(c\)-th copy in a bin

  • precedences: pairs \((i, i')\) where item type \(i\) dominates item type \(i'\)

Variables:

  • \(y_{t,k} \in \{0, 1\}\): \(y_{t,k} = 1\) iff bin instance \((t, k)\) is used (for the bin-packing and variable-sized-bin-packing objectives; for the other objectives, all the bin instances are available, and \(y_{t,k}\) is replaced by 1 below)

  • \(x_{i,t,k,c} \in \{0, 1\}\): \(x_{i,t,k,c} = 1\) iff bin instance \((t, k)\) contains at least \(c\) copies of item type \(i\)

  • \(z_{i,i'} \in \{0, 1\}\), for each precedence \((i, i')\): \(z_{i,i'} = 1\) iff the copies of item type \(i'\) may be packed

Encoding the copies of an item type in a bin as “at least \(c\) copies” variables gives a binary variable per copy without symmetry between the copies, and lets the consumption of a resource depend on the copy.

Objective: depending on the objective

\[\max \sum_{i,t,k,c} p_i \, x_{i,t,k,c} \qquad \text{(knapsack)}\]
\[\min \sum_{t,k} c_t \, y_{t,k} \qquad \text{(variable-sized bin packing)}\]
\[\min \sum_{t,k} y_{t,k} \qquad \text{(bin packing)}\]

Constraints:

  • Ordered copies

\[\forall i, t, k, c \qquad x_{i,t,k,c+1} \le x_{i,t,k,c}\]

  • Demand: each item type is packed between its minimum and its maximum number of copies (for the feasibility, bin-packing and variable-sized-bin-packing objectives, both are the number of copies)

\[\forall i \qquad q^{\min}_i \le \sum_{t,k,c} x_{i,t,k,c} \le q_i\]

  • Length: the items of a bin instance fit in its length, if it is used

\[\forall t, k \qquad \sum_{i,c} \ell_i \, x_{i,t,k,c} \le L_t \, y_{t,k}\]

  • Weight: the items of a bin instance don’t exceed its maximum weight

\[\forall t, k \qquad \sum_{i,c} w_i \, x_{i,t,k,c} \le W_t \, y_{t,k}\]

  • Resources: the items of a bin instance don’t exceed the capacity of its resources

\[\forall t, k, r \qquad \sum_{i,c} a_{i,r,c} \, x_{i,t,k,c} \le C_{t,r} \, y_{t,k}\]

  • Mandatory bins

\[\forall t, \; \forall k \le m_t \qquad y_{t,k} = 1\]

  • Precedences, given with the instance (the Benders decomposition for rectangle uses them in its master problem): no copy of a dominated item type is packed unless all the copies of the dominating item type are packed. They only matter for the knapsack objective.

\[\forall (i, i') \qquad \sum_{t,k,c} x_{i,t,k,c} \ge q_i \, z_{i,i'} \qquad \sum_{t,k,c} x_{i',t,k,c} \le q_{i'} \, z_{i,i'}\]

  • Bin usage order, for the bin-packing objective: the bin instances are used in the order in which they are given, all the instances of a bin type before the ones of the next bin type (with \((t, k)\) and \((t', k')\) consecutive instances in this order); for the variable-sized-bin-packing objective, the same holds within each bin type, which breaks the symmetry between its instances

\[y_{t,k} \ge y_{t',k'}\]

Symmetry breaking. The bin instances of a bin type are interchangeable. They can be relabeled by increasing order of the smallest label of the items they contain, the items being labeled by item type, by increasing number of copies. Then the \(k\)-th bin instance of a type can’t contain more than a given number of copies of each item type, and the variables \(x_{i,t,k,c}\) beyond this number are not created.

Bin packing¶

For the bin-packing objective, a tree search is run first, which gives a solution and a lower bound on the number of bins. The MILP is then solved as a sequence of feasibility problems, packing all the items in a fixed number of bins, trying the numbers of bins in increasing order from the lower bound; the first feasible one is optimal. If the tree search already found a solution, only the numbers of bins strictly below its number of bins are tried.

For the variable-sized-bin-packing objective, the number of bin instances of each bin type in the model is bounded, using a tree search.

Solver¶

The MILPs are solved with HiGHS. The solutions found by the solver are reported as they are found, the bound of the solver is reported as a bound of the instance, and the solver is stopped as soon as its bound shows that it can’t improve the best solution found.

Automatic selection¶

It is not part of the automatic selection. It can be selected with --use-milp-assignment 1 (CLI) or use_milp_assignment (Python).
