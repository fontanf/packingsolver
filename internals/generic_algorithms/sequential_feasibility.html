Sequential feasibility¶

Objectives¶

This algorithm solves the bin-packing, bin-packing-with-leftovers, open-dimension-x, open-dimension-y and open-dimension-xy objectives, with an algorithm solving the feasibility objective. It is not selected by itself: it is used by the algorithms which only solve the feasibility objective directly.

Principle¶

It repeatedly solves a feasibility sub-problem asking whether all the items fit into a shrinking amount of space:

  • bin-packing: a number of bins;

  • bin-packing-with-leftovers: a number of bins, the last one restricted to a length;

  • open-dimension-x and open-dimension-y: a bin restricted to a length along the open dimension;

  • open-dimension-xy: a bin restricted to a length along both dimensions, with the given aspect ratio.

It starts from an estimate computed from the total space of the items. As long as the sub-problem is feasible, it tightens the space based on the solution just found (one bin fewer than it actually used, or slightly less than the length it actually reached) and solves it again. It stops as soon as a sub-problem turns out infeasible (or can’t be solved within its budget), and returns the last feasible solution found.

Warm start. In the irregular version, each sub-problem, except the first one, receives the previous solution found as a warm start. It is generally not a feasible solution of the sub-problem: the space has been shrunk, so some items may stick out of their bin, and the bins which aren’t available anymore are dropped together with their items. It is up to the inner algorithm to repair it, and the irregular local search does.

Uses¶

  • irregular: the local search (shrinking the open dimension by 0.1% at each step), the tree search with periodic packings, the tree search with maximal spaces, and the tree search for the open-dimension-xy objective;

  • rectangleguillotine: the tree search with maximal spaces, for the open-dimension-x, open-dimension-y and bin-packing-with-leftovers objectives with a single bin.

The MILP assignment and column generation algorithms use a similar scheme for the bin-packing objective, trying the numbers of bins in increasing order from a lower bound.
